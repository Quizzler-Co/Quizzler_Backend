Factorial

Given a non-negative integer n, return n! (n factorial).
n! = n × (n-1) × (n-2) × ... × 2 × 1
0! = 1

Note: The result may be large, so use long type for the return value.

Example:
Input: 5
Output: 120

Input: 10
Output: 3628800

Your method signature:
public static long factorial(int param1)
