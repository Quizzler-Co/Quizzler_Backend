Extend the Quizzler quiz system to support coding questions alongside MCQs for technical rounds. The Java Judge service is already integrated in the backend.

BACKEND API (already integrated):
- Base URL: http://localhost:8086/api/v1/judge
- GET /api/v1/judge/problems?difficulty=EASY|MEDIUM|HARD - Get all problems
- GET /api/v1/judge/problems/{problemId} - Get problem details  
- POST /api/v1/judge/submit - Submit code solution
  Request: { "problemId": "string", "code": "string" }
  Response: { "verdict": "ACCEPTED|WRONG_ANSWER|COMPILATION_ERROR|RUNTIME_ERROR|ERROR", "message": "string", "expectedOutput": "string", "actualOutput": "string" }
